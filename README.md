# 国际会议同声传译和发言队列控制

源提示词摘要：主持人维护代表发言队列、剩余时间、议题和临时插话；翻译团队维护多语种频道、术语和译员交接；字幕人员修正实时文本。队列调整保留版本，发言者切换后旧译文不会误绑定，并提供低延迟大屏模式和多会议厅隔离。

## 技术栈

Qwik City、TypeScript、Qwik UI、Qwik stores、TanStack Query、Modular Forms、Zod、qwik-speak。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：`62029`

## 可用流程

- 多会议厅独立维护代表、议题和发言队列，切换厅时数据互不影响。
- 发言人从排队、发言中、完成到跳过，支持临时插话和剩余时间调整。
- 多语种频道维护译员、术语和交接；交接后新增字幕归属新译员。
- 实时字幕支持版本化修正，低延迟模式只保留关键状态并停用非必要动态。
- 数据保存在浏览器 localStorage，刷新后继续保留。

## 按厅发言计时（`src/timing/`）

纯 TypeScript 内核（`core.ts`，不依赖框架/DOM）+ Qwik 控制台（`timing-console.tsx`），规则：

- **按厅独立账本**：每个会议厅各自维护队列、容量、版本号与改动账本，切厅不串账。
- **改动逐笔累加**：时长加减、换位、临时插话都生成一条账本，时长变动以 `Adjustment` 增量保存，永不整体覆盖。
- **改一处、后续全重算**：每次保存从厅起点重排所有时段的起止时间。
- **超容量先挤最后的代表**：超出厅内容量时，从队尾代表起逐个降级为候补，账本写明"差多少秒"；插话不降级，若仅插话就超容则标 `overCapacity`。
- **提前结束把时间还回厅里**：实际短于计划的秒数计入 `returnedSeconds`，空出容量时候补按 FIFO 自动递补。
- **两窗口同改一厅**：基于版本号乐观提交；改不同段落自动合并且双方加减逐笔保留，改同一段落则拒绝后保存方并列出各自改过的段落。
- **旧数据升级**：检测 `conference-interpretation-v1` 后按原计划时长补齐为 v2，容量不足时同样走降级流程。
